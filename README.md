Online Book Store SQL Data Analysis

Project Overview
This project focuses on analyzing an online bookstore database using SQL. It demonstrates how SQL queries can be used to retrieve, filter, summarize, and analyze business data.

Tools Used
- MySQL Workbench
- SQL

Database Tables
1. **Books** – Book details, author, genre, price, and stock.
2. **Customers** – Customer information and location.
3. **Orders** – Order details, quantities, and total amounts.

SQL Concepts Covered
- SELECT, WHERE, ORDER BY
- DISTINCT and LIMIT
- Aggregate Functions: SUM, AVG, COUNT
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Business analysis queries

Business Questions
- Which books belong to the Fiction genre?
- What is the total stock available?
- Which books generate the most orders?
- What is the total revenue?
- Which customers have placed at least two orders?
- Which author has sold the most books?
- Which customer has spent the most?

 Project Files
- `OnlineBookStore.sql` – Database creation, table creation, and SQL queries.
- `screenshots/` – Query execution results.

Key Learning Outcomes
- Practiced SQL querying and data analysis.
- Used joins to combine multiple tables.
- Applied aggregate functions to calculate business metrics.
- Analyzed customer orders, book sales, and inventory.
